# Version 2.1.4

Version 2.1.4 was released on 2019/12/18.

## Changes in This Release
* Ensure task wait returns a boolean.
* Add path style boolean parameter to connection.
* Add download result feature to tasks.
* Update C# language version to 8.0.
* Add experimental namespace `QarnotBetaSDK` for unstable features.
* Implement `executionTimeByCpuModel` and `executionTimeGhzByCpuModel` in task status.
* Change `ClockRatio` type from long to double.
