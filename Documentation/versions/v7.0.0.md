# Version 7.0.0

## Changes in This Release
* Drop support for the .NET Framework 4.5 (`net45`) target and move to `netstandard2.1`. As `netstandard2.1` is not implemented by .NET Framework, the SDK is now consumable only from .NET Core 3.0+ / .NET 5+ (and other `netstandard2.1`-compatible runtimes).
* Remove the net45-specific compatibility code (the `WebRequestHandler`-based client handlers, the `Amazon.Runtime.HttpClientFactory` shim, and the related `[Obsolete]` markers), so the S3 custom `HttpClient` factories are now fully functional on every supported target.
* Clean up the build metadata accordingly (project file, NuGet spec, CI framework matrix, documentation generation) and remove the now-unused `packages.config` and `app.config` files.
* Add `Connection.RetrieveUserComputingQuotasUsageAsync` and `Connection.RetrieveOrganizationComputingQuotasUsageAsync` to read the current computing quota usage of the user and of their organization. The latter breaks the organization's running usage down per user if the requester has the necessary permissions.
