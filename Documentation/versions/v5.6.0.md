# Version 5.6.0

Version 5.6.0 was released on 2022/12/12.

## Changes in This Release
* Add `CpuModelHardwareConstraint` hardware constraint.
* Add CPU model search feature.
* Add support for task and pool retry settings.
* Expose task completed instances.
* Expose new retry settings (deprecates `maxRetriesPerInstance` field).
* Fix Newtonsoft.Json vulnerability GHSA-5crp-9r3.
