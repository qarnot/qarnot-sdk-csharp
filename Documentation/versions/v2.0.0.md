# Version 2.0.0

Version 2.0.0 was released on 2019/05/09.

## Changes in This Release
* Add user agent to API calls.
* Implement retrieve pool by tags.
* Implement retrieve and create-or-retrieve on buckets.
* Add pool and task update capabilities.
* Add elastic properties to a pool.
* Add retrieve by UUID and shortname.
* Implement precise task and pool filtering.
* Remove legacy QDisk.
* Build SDK for net45 and netstandard2.0.
