# Version 5.2.0

Version 5.2.0 was released on 2021/10/22.

## Changes in This Release
* Add running instances and cores to user information.
* Add support for pool usage.
* Add execute attempt count on tasks.
* Use paginated API calls when retrieving tasks and jobs.
* Deprecate `RetrieveXByName` methods, replaced by `RetrieveXByShortname`.
