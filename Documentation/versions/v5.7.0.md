# Version 5.7.0

Version 5.7.0 was released on 2023/03/27.

## Changes in This Release
* Add commands to retrieve task and pool outputs per instance.
* Fix: set privileges property as nullable to avoid overriding default values for tasks in pools.
* Fix: use direct reference to private resource field in `QTask` and `QPool` so that `task.Resources.Add(...)` behaves as intuitively expected.
* Fix: attached pool UUID and shortname for in-pool task status.
