# Version 3.0.0

Version 3.0.0 was released on 2020/06/12.

## Breaking Changes
* Remove use of memory stream for bucket object download; the stream is no longer seekable.

## Changes in This Release
* Add script to build documentation.
* Add an unsafe certificate handler class to bypass certificate verification.
* Add task and pool `CoreCount` in `PerRunningInstanceInfo`.
* Add custom certificate verification support to the SDK.
* Ensure all async calls accept a `CancellationToken`.
* Add previous state, state transition date and previous state transition date fields.
* Add pool preparation command line.
* Fix randomly failing tests.
