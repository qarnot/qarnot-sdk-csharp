# Version 5.5.0

Version 5.5.0 was released on 2022/06/16.

## Changes in This Release
* Add support for task and pool privileges.
* Add TTL support to advanced buckets.
* Rework linear and exponential retry handlers (previously constant and linear).
* Retry on internal server error.
* Rename 'Node' to 'Slot' for elastic settings.
