# Version 5.8.0

Version 5.8.0 was released on 2023/05/02.

## Changes in This Release
* Add support for `QPool.Scaling` specifications with time-based fixed rules and dynamic rules based on queued task count.
* Fix: job shortname is now properly retrieved when retrieving a pool by UUID.
* Fix: prevent exceptions when dynamically loading tasks and pools from the remote API.
