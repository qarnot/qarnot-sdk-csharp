# Version 6.4.0

Version 6.4.0 was released on 2026/07/03.

## Changes in This Release
* Add support for project's budgets, with helpers to retrieve all or only active budgets of a project.
* Add helper to retrieve a project by its uuid.
* Add helper to retrieve the default project.
* Add helpers to retrieve account credits and consumed credits by task/pool.
* Modernize Ceph in integration tests.
* Add change logs in generated documentation.
