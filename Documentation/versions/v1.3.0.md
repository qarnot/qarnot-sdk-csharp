# Version 1.3.0

Version 1.3.0 was released on 2019/03/01.

## Changes in This Release
* Add `RetrieveByUuid` and `RetrieveByShortname` feature.
* Implement retrieve and create-or-retrieve on buckets.
* Add `Run` and `Wait` features on tasks.
* Add `Delete` with purge feature.
* Avoid deadlocks on getters, setters and async functions.
* Update dependencies.
