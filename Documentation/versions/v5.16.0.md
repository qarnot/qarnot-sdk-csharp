# Version 5.16.0

Version 5.16.0 was released on 2026/02/05.

## Changes in This Release
* Add support for snapshot status: return a snapshot ID when requesting an instant snapshot.
* Add `GetSnapshotStatusAsync` method on tasks to retrieve snapshot status.
* Add `WaitCompletionAsync` method on snapshot objects to wait for snapshot completion.
* Fix: deserialization of VPN connection.
