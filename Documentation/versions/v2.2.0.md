# Version 2.2.0

Version 2.2.0 was released on 2020/03/18.

## Changes in This Release
* Add SDK unit tests.
* Allow users to use the configured S3 client.
* Add `UpdateResourcesAsync` method to the pool object.
* Add VPN connection to the task API status.
* Fix incorrect folder hierarchy when synchronizing from storage.
* Fix waiting time for tasks.
