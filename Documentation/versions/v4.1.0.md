# Version 4.1.0

Version 4.1.0 was released on 2021/04/29.

## Changes in This Release
* Add `RunningCoreCount` and `RunningInstanceCount` fields to tasks and pools.
* Add more timing information in tasks and pools.
* Add optional search prefix parameter to `ListFilesAsync`.
* Add support for "results prefix" to specify a prefix when uploading to the results bucket.
* Add support for "snapshot bucket" and "snapshot bucket prefix" for snapshot results.
* Add resources bucket prefix filtering and stripping.
